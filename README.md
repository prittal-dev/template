# Agency Template Studio & Client Live Pitch Engine

A high-performance web platform built to showcase website frameworks, customize branding in real-time for prospective clients, and close deals during live pitches.

## 🚀 Live Pitch Engine & Templates Catalog

| Template | Industry / Niche | Key Tech Stack |
| :--- | :--- | :--- |
| **Plaza Quartz** (`demo_plazaclock`) | Luxury Horology & Corporate Atelier | React 18, Tailwind, Locomotive Scroll |
| **Electwell Engineers** (`jagmohan`) | Heavy Industrial Fans & Blowers | React, Tailwind, B2B RFQ Lead Funnel |
| **Padma Cable** (`padmacables`) | Power Cables & Infrastructure | React, Tailwind, Lenis Smooth Scroll |
| **Young Wheels** (`youngwheels`) | Kids Toys & Consumer Goods E-Commerce | React, Tailwind, Motion |

## 🛠️ Quick Start

### Run the Showcase Studio Hub
```bash
npm run dev
```
Then visit `http://localhost:5000/`.

For complete documentation on personalizing client brands, using device simulators, and adding new templates, see [HOW_TO_USE.md](HOW_TO_USE.md).
